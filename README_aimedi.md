# MediBridge AI Product Pack

Files:
- `PRD.md` — product requirements, personas, journeys, functional requirements, acceptance criteria and release plan.
- `TRD.md` — MERN + Vite + SCSS technical requirements, API proposal, data models, security, tests and Python-to-Node migration plan.
- `Architecture.md` — system context, component boundaries, data flows, deployment, integration contracts, resilience and ADRs.
- `Mockup.html` — responsive, clickable frontend prototype with patient records, AI summary, provider comparison, scheme checklist, consent preview, doctor workspace, follow-up and emergency views.

## Open the mockup
Open `Mockup.html` directly in a modern browser. It is a self-contained visual prototype; it does not connect to a backend, persist data, upload documents, call real providers, assess real scheme eligibility or book appointments. All sample data is fictional and visibly labelled.

## Important implementation note
These documents describe a proposed baseline, not the current repository state. Audit the actual project before changing it. Treat all integrations as unconnected until configured, authorized, tested and verified.
